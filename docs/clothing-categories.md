# Категории одежды

В коллекции `clothing` обязателен select «Категория одежды» со значениями `set` («Часть сета»), `hazmat` («Хазмат»), `ring` («Кольцо»). У части сета обязательна связь с существующим `equipment-sets`. У хазмата и кольца связь пуста. Категория не влияет на необязательный рецепт.

В админке «Сет» виден у части сета. Если PATCH меняет часть на самостоятельный предмет и опускает `equipmentSet`, сервер очищает прежнюю связь. Явный `null` допустим для самостоятельных предметов. Явная ссылка для них отклоняется. Смена на часть сета требует ссылки на комплект. Состав и защита удаления продолжают работать через `clothing.equipmentSet`.

## Переход существующей базы

Для рабочей конфигурации отключён общий development schema push. В этой базе план Drizzle предлагает 22 посторонних операции. Целевые изменения соответствуют enum, который генерирует PostgreSQL-адаптер Payload:

```sql
CREATE TYPE public.enum_clothing_category AS ENUM ('set', 'hazmat', 'ring');
ALTER TABLE public.clothing ADD COLUMN category public.enum_clothing_category;
```

Перед этапом заполнения нужно сверить записи с исходным снимком. В проверенной базе категория `set` соответствует 16 связанным предметам, `hazmat` — единственной записи `khazmat-fermer`. Заполняются только строки с пустой категорией, в транзакции. Если состав отличается, сначала уточните классификацию. После повторной сверки и проверки отсутствия NULL применяется единственная заключительная операция:


## Ручная проверка

1. На тестовой базе откройте «Одежда» в админке. Создайте запись каждой категории без рецепта. У части сета выберите комплект.
2. Переведите часть в кольцо, сохраните и проверьте, что предмет исчез из состава сета. Переведите обратно и выберите сет.
3. На `/clothing` проверьте порядок разделов «Сеты», «Хазматы», «Кольца». Группа колец появляется после создания первой записи. Детали всех предметов открываются по `/clothing/[slug]`, детали сетов — по `/clothing/sets/[slug]`.
4. Включите крафт у тестового кольца и заполните рецепт. Проверьте страницу предмета и `/craft`.
